# LONGEVITY JOURNAL

건강·항노화·러닝 매거진형 블로그입니다. 기존 Asset Rebalancing Automation과 별도 저장소입니다.

## 구성
- index.html: 모바일/PC 반응형 매거진 홈, 카테고리, 검색, 글 읽기
- posts.js: 게시글 3개(모두 예시 원고)

## GitHub Pages 게시
Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
배포 완료 후 https://jacobkang80.github.io/longevity-journal/ 에서 확인합니다.

## 글 추가
posts.js의 JOURNAL_POSTS 배열에 slug, category, date, title, excerpt, tags, html을 추가합니다. category는 health, running, research 중 하나입니다.
